BGM files
=========

Put licensed local music files here:

- `bgm-1.mp3`
- `bgm-2.mp3`

The game will try to play these files from `audio/bgm-1.mp3` and
`audio/bgm-2.mp3`. If the files are missing, the game keeps running and only
the generated sound effects are used.

Use tracks only when you own the rights or have permission to use them.
